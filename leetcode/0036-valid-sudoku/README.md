## Problem Statement

<p>Determine if a&nbsp;<code>9 x 9</code> Sudoku board&nbsp;is valid.&nbsp;Only the filled cells need to be validated&nbsp;<strong>according to the following rules</strong>:</p>

<ol>
	<li>Each row&nbsp;must contain the&nbsp;digits&nbsp;<code>1-9</code> without repetition.</li>
	<li>Each column must contain the digits&nbsp;<code>1-9</code>&nbsp;without repetition.</li>
	<li>Each of the nine&nbsp;<code>3 x 3</code> sub-boxes of the grid must contain the digits&nbsp;<code>1-9</code>&nbsp;without repetition.</li>
</ol>

<p><strong>Note:</strong></p>

<ul>
	<li>A Sudoku board (partially filled) could be valid but is not necessarily solvable.</li>
	<li>Only the filled cells need to be validated according to the mentioned&nbsp;rules.</li>
</ul>

## Constraints

- <code>board.length == 9</code>
- <code>board[i].length == 9</code>
- <code>board[i][j]</code> is a digit <code>1-9</code> or <code>&#39;.&#39;</code>.

## Solution

```py
class Solution:
    def isValidSudoku(self, board: list[list[str]]) -> bool:    
        def check(col,row,value):
            count=0
            for i in range(9):
                if(board[i][row]==value):
                    count+=1
            for j in range(9):
                if(board[col][j]==value):
                    count+=1
            row = row-(row%3)
            col = col-(col%3)
            for i in range(col,col+3):
                for j in range(row,row+3):
                    if(board[i][j]==value):
                        count+=1
            if(count>3):
                return False
            return True
            
        for i in range(len(board)):
            for j in range(len(board[i])):
                if(board[i][j]=='.'):
                    continue
                elif(not check(i,j,board[i][j])):
                    return False
        return True
```
